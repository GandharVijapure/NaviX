What's real vs. simulated in this build
Real, working code
  • FastAPI backend, SQLAlchemy models, JWT auth, bcrypt hashing
  • WebSocket live updates across every dashboard
  • Facility/nearest-facility, SOS, lost-person, announcements, routes, authorities, dispatch APIs
  • PWA offline caching (IndexedDB + service worker), background sync of queued SOS/reports
  • Waypoint arrow-mode navigation, working fully offline once a route is downloaded
Simulated / future hardware
  • Actual LoRa RF transmission and real multi-hop mesh routing
  • Bluetooth link between field node and Main Volunteer's phone
  • ESP32 firmware itself (device-side code)
  • Real government/authority system integrations
  • AI crowd-density prediction, facial recognition, drones, voice-over-LoRa
